# Fidelia Oko — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript. It showcases selected projects, my engineering experience, and the way I approach building software.

## Features

* Dark and light theme switching
* Responsive layouts for mobile, tablet, and desktop
* Scroll-based reveal animations
* Lightweight parallax effects
* Project case studies
* Career timeline
* Engineering approach and lessons learned
* Semantic HTML and accessible UI
* Minimal use of external dependencies

## Getting Started

This is a static website, so no build step or package installation is required.

### Run locally

Open `index.html` directly in your browser, or start a local development server:

```bash
python3 -m http.server 5173
```

Then visit:

`http://localhost:5173`
